## Програма OneTimePad (ПЗ2)

| Файл | Призначення |
|---|---|
| `Pad.cs` | XOR із циклічним ключем, генерація випадкового одноразового ключа (`RandomNumberGenerator`), шифрування й дешифрування тексту в UTF-8 |
| `Attack.cs` | Атака за відомим відкритим текстом: `K = C ⊕ P`, пошук найкоротшого періоду потоку ключа, дешифрування повідомлення |
| `Program.cs` | Консольне меню: шифрування, дешифрування, атака, демонстрація |

### Запуск

Потрібен .NET SDK 8.0 або новіший.

```bash
cd PZ_2/OneTimePad
dotnet run
```

Пункти меню:

1. Зашифрувати — ключ вводиться словом (повторюється циклічно) або порожнім рядком для випадкового одноразового ключа.
2. Розшифрувати — шифротекст у hex, ключ словом або в hex з префіксом `hex:`.
3. Атака — перехоплений шифротекст (hex) і відомий початок тексту.
4. Демонстрація — та сама атака проти короткого повторюваного ключа «ключ» (ключ і весь текст відновлюються) і проти справжнього одноразового ключа (відновлюється лише відомий фрагмент).

Приклад з ПЗ1: текст `моє завдання третє`, ключ `Ельмір` → шифротекст
`002900050018F06C664661506245646B615C6D6C6C475EA00117013B0139013E0002`; атака з відомим текстом відновлює ключ «Ельмір» (період 12 байт).
